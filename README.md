# JOB LISTEN EVENT FROM VECHAIN & PUSHLISH MESSAGE TO RABBITMQ


## INSTALL
### Require
- Node version > 16.0
### Run install package
- npm install
### Coppy file env_example to file `.env`
### Run by event
```
    npm run supply       (event supply)
    npm run borrow       (event borrow)
    npm run repay        (event repay)
    npm run withdraw     (event withdraw)
    npm run reserve-update
    npm run job-lending  (cron jobs lending actions)
```
